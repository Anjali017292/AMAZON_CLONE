# amazon

**Amazon Clone (Frontend Project)**
Overview

This project is a frontend clone of the popular e-commerce platform Amazon.
It is designed using HTML and CSS to replicate the basic user interface and shopping experience of the Amazon homepage.

The project focuses on responsive web design, layout structuring, and modern UI components used in real-world e-commerce websites.


**Features**
Responsive navigation bar
Search bar section
Product categories section
Hero/banner section
Product cards with images and prices
Footer section similar to Amazon
Responsive layout for different screen sizes


**Technologies Used**
HTML5
CSS3
